This directory contains the code for Hierarchical Interval Halving, a modified version of the algorithm described in [1]. The following figure explains how the algorithm performs segmentation using piecewise polynomial fits.

Hierarchical_Interval_Halving.py contains the implementation of the algorithm. Hierarchical_Interval_Halving_helper.ipynb contains example code which demonstrates how to apply the algorithm.

References: 

[1] Sourabh Dash,Mano Ram Maurya,Venkat Venkatasubramanian,Raghunathan Rengaswamy. "A novel interval-halving framework for automated identification of process trends".  https://doi.org/10.1002/aic.10014. AIChE Journal. Volume50, Issue1, January 2004, Pages 149-162
